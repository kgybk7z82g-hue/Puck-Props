PUCK PROPS — personal NHL dashboard
Open index.html in a modern browser. The scoreboard and player history require an internet connection and a browser that permits requests to the NHL public API.
For iPhone installation as a home-screen web app, host these files on an HTTPS static host (for example GitHub Pages), open the hosted page in Safari, tap Share, then Add to Home Screen.
Player history: enter an NHL player ID. Career logs are fetched season by season; the opponent filter and recent-meeting samples are applied locally. Data coverage depends on NHL API availability. This is an unofficial personal project.
